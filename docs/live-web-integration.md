# Free-model web integration

October13,2026. The user approved the bounded design: tested free Nemotron profile, persistent request counts, billing checks, no paid fallback and a visible safe pause.

The normal application factory now uses `FreeLiveModel` in live mode. Current model and endpoint zero pricing and required tool/reasoning capabilities are verified before inference. Every chat request passes through the existing zero-price transport: optional reasoning disabled, native tools required, maximum600 output tokens, zero provider price ceilings, no fallback, persistent1000-request session cap, provider allowance and before/after account reconciliation. The provider key must have a spending limit of1 dollar or less. Missing response costs remain unknown under the user's authorized policy; reported cost, increased billed usage or decreased balance still stops requests.

The private session record defaults to `LOGISTICS_DATA_DIR/free-model-requests.json`. `LOGISTICS_BILLING_STATE` can instead point at an existing private evaluation ledger so counts continue across testing and the app. Use one app worker and do not run the app and evaluator concurrently on the same record. The session cap never resets automatically; provider daily allowance is a separate counter. Restart preserves pauses. Pages show a selected local snapshot and never make model/billing calls merely by opening. Form actions return to a visible pause message; API clients receive503 with a fixed, sanitized reason. Recorded proposals and approved assignments remain available. A known paused investigation is rejected before reserving another model attempt.
